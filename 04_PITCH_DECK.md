## Delivery tips (Round 2)
- **Time it:** aim for the allotted window minus 30s. Practice with a timer.
- **Story → problem → solution → demo → impact → vision.** Demo in the middle, not the end, so questions land on substance.
- **Energy + eye contact.** Solo founders win on conviction. You believe vulnerable people deserve a guardian — show it.
- **Have the live URL + a recorded demo + localhost** all ready. Assume the wifi gods are hostile.
- **End every answer by tying back to impact.**

## Likely judge questions (prep answers)
1. **"How is this different from spam/scam filters?"** → Intent vs keywords; preventive vs reactive; cross-channel; the Trusted Circle.
2. **"How accurate is it / false positives?"** → LLM intent detection + explainability lets users verify; benign conversations score safe (show the safe fixture); threshold is tunable; family confirmation reduces false-positive harm.
3. **"How do you detect cloned voices?"** → Today: linguistic/behavioral manipulation detection (works regardless of voice). Roadmap: dedicated synthetic-voice forensic model as a second signal.
4. **"What's the business model?"** → B2B2C licensing to banks/telcos/insurers + SDK; the buyer saves fraud-reimbursement costs and churn.
5. **"Privacy — you're listening to calls?"** → Roadmap is on-device/edge inference; user-consented, opt-in, data never leaves the phone; designed for vulnerable users with caregiver consent.
6. **"Why you / can this scale?"** → Built solo end-to-end in 6 days; the engine is model- and channel-agnostic, so scaling is integration, not reinvention.
